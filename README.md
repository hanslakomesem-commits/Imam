# ZAIN.NET - Sistem Jilid Skripsi & Nota Otomatis UIN Madura

Aplikasi web modern untuk pemesanan jilid skripsi, live kalkulator biaya, dan cetak struk/nota otomatis untuk **ZAIN.NET**.

## Fitur Utama
1. **Pilihan Jenis Jilid:**
   - **Hard Cover:** Rp 30.000 - Rp 50.000 / buku (warna sesuai standar fakultas UIN Madura).
   - **Soft Cover:** Rp 15.000 / buku.
2. **Durasi Pengerjaan & Jadwal Pengambilan Pasti:**
   - Paket 1 Hari Jadi, 2 Hari Jadi, dan 3 Hari Jadi (Normal).
   - Pengambilan hasil naskah otomatis diatur pukul 08:00 WIB.
3. **Layanan Tambahan Wisuda & Repositori:**
   - Cetak Artikel, CD Softcopy, Buku SKEK, Pisah Berkas Perpus, Dummy Book PIAUD, Cetak A5 Bolak-Balik Tadris IPA.
4. **Struk Pembayaran & Bukti Pengambilan:**
   - Struk simpel, rapi, dan to-the-point.
   - Pilihan transaksi: **Bayar Sekarang**, **DP (Uang Muka)**, **LUNAS**, atau **Bayar Nanti (di Loket)**.
   - Dilengkapi tombol **Unduh Struk (Gambar PNG)**, **Cetak / PDF**, dan **Kirim ke WhatsApp**.

## Cara Menjalankan Project

### 1. Install Dependencies
```bash
npm install
```

### 2. Jalankan Server Development
```bash
npm run dev
```
Akses di browser pada: `http://localhost:3000`

### 3. Build untuk Produksi
```bash
npm run build
```
